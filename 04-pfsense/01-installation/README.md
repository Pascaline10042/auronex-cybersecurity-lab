# Installation pfSense

Documentation de l'installation de pfSense dans le laboratoire virtuel AURONEX.

## Environnement

* VirtualBox
* pfSense
* Ubuntu
* Réseaux virtuels

## Objectif

Mettre en place un pare-feu pfSense fonctionnel dans un environnement de laboratoire afin de pratiquer la cybersécurité défensive.
