# Jour 1 — Comprendre la machine

## 🎯 Objectif

Comprendre les principaux éléments d'un ordinateur et le rôle du système d'exploitation.

---

## 1. Matériel informatique

Le matériel informatique (**hardware**) désigne les éléments physiques d'un ordinateur.

### Exemples

- CPU / processeur
- RAM
- SSD / HDD
- Carte mère
- Carte réseau
- Clavier
- Écran

À l'inverse, les programmes et systèmes sont des **logiciels (software)**.

---

## 2. CPU

**CPU (Central Processing Unit)** : c'est le processeur de l'ordinateur.

Son rôle principal est d'exécuter les instructions des programmes.

Le CPU possède plusieurs cœurs (**cores**) qui permettent notamment de traiter plusieurs tâches en parallèle.

---

## 3. RAM

**RAM (Random Access Memory)** : c'est une mémoire de travail rapide utilisée pendant l'exécution des programmes.

Elle stocke temporairement les données dont les programmes ont besoin.

La RAM est une mémoire **volatile** : son contenu est perdu lorsque l'ordinateur est éteint.

---

## 4. Stockage

Le stockage permet de conserver durablement les données.

### Exemples

- SSD
- HDD
- Clé USB

On y retrouve notamment :

- le système d'exploitation ;
- les programmes ;
- les fichiers personnels.

### RAM vs stockage

| RAM | Stockage |
|---|---|
| Mémoire de travail | Conservation des données |
| Temporaire | Persistant |
| Utilisée pendant l'exécution | Contient les fichiers et programmes |
| Rapide | Capacité généralement plus importante |

---

## 5. Système d'exploitation

Le système d'exploitation (**OS**) est le logiciel principal qui permet à l'utilisateur et aux applications d'utiliser l'ordinateur.

### Exemples

- Windows
- Linux
- macOS

Le système d'exploitation gère notamment :

- les fichiers ;
- les utilisateurs ;
- les permissions ;
- les processus ;
- la mémoire ;
- le matériel ;
- le réseau.

---

## 🔐 Lien avec la cybersécurité

Comprendre le fonctionnement d'un ordinateur est une base importante en cybersécurité.

Avant d'analyser une attaque ou de sécuriser une machine, il faut comprendre :

- comment le matériel fonctionne ;
- comment le système utilise la mémoire ;
- comment les programmes sont exécutés ;
- comment les fichiers sont stockés ;
- comment le système d'exploitation gère les ressources.

---

## ✅ Validation du Jour 1

À la fin de cette journée, je dois être capable d'expliquer :

- la différence entre hardware et software ;
- le rôle du CPU ;
- le rôle de la RAM ;
- la différence entre RAM et stockage ;
- le rôle d'un système d'exploitation.
